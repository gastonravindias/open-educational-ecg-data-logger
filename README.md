# Open Educational ECG Acquisition and Data-Logging Platform

Version: **v1.0.0**

Repository URL intended for submission: **https://github.com/gastonravindias/open-educational-ecg-data-logger**

## Purpose
A transparent AD8232 + ESP32-C3 platform for supervised biomedical-engineering education, raw ADC logging, display/status demonstrations and open-hardware learning.

## Evidence boundary
The retained project evidence demonstrates one assembled breadboard prototype, OLED operation and qualitative serial waveform streaming. Quantitative timing, dropped-sample, runtime, solar-efficiency, clinical-accuracy and independent-replication results were not retained and are not claimed.

## Main contents
- editable SVG wiring diagram
- exported diagrams and prototype photographs
- reference firmware with nominal 250 samples/s and raw 12-bit ADC logging
- pin map and BOM
- assembly and safety guidance
- qualitative evidence matrix
- quantitative test protocol
- optional solar-extension design calculation
- licence information

## Safety
Not a medical device. Do not use for diagnosis, treatment or patient monitoring. Quantitative testing should use an ECG simulator. See `safety/safety_policy.md`.
