# Revised Manuscript Figures — v1.1.0

This directory contains figures prepared for the Journal of Open Hardware peer-review revision.

## Files

- `Figure1_Revised_Architecture.png` — revised educational ECG acquisition and data-logging architecture.
- `Figure2_Revised_Hardware.png` — improved crops of retained prototype photographs.
- `Figure3_Full_Connection_Diagram.png` — detailed connection diagram for the revised educational core.
- `Figure4_Revised_Waveform_Evidence.png` — retained qualitative waveform evidence with an explicitly labelled image-derived trace.

## Evidence note

The figures do not introduce reconstructed experimental measurements.

Figure 4 includes an image-derived trace solely to improve the legibility of retained photographic evidence. It is not raw numerical ADC data and must not be interpreted as calibrated ECG data.

The original numerical serial waveform dataset was not retained.
