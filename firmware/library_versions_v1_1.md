# Software Dependency / Version Reference

Reference environment:
- Arduino IDE 2.x family
- Arduino-ESP32 core 3.x family
- Wire
- SPI
- SD
- Adafruit_GFX
- Adafruit_SSD1306
- Adafruit_INA219
- RTClib

Exact historical installed versions were not retained and are not invented. Every new replication should record operating system, Arduino IDE version, ESP32 core/board target, exact external-library versions, firmware commit/tag and non-default build settings.
